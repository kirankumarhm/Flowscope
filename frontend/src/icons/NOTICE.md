# Icons used by the Architecture view

## AWS service icons (`aws-*.svg`)

From the official AWS Architecture Icons package (release 2026-07-31,
https://aws.amazon.com/architecture/icons/). AWS permits customers and partners to use these
icons to create architecture diagrams. The artwork is unmodified apart from removing the XML
declaration and `<title>` element.
